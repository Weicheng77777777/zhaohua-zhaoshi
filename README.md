# 朝花朝拾

《朝花朝拾》是我的个人文字计划。

鲁迅先生的《朝花夕拾》让我明白，许多往事会在时间之后重新发光。  
但我也常常觉得，生活不一定非要等到很久以后才值得记录。

有些花，不必等到黄昏再拾。  
有些梦，不必等到醒来很久才写。  
有些情绪、片刻、普通日子里的微光，也可以在今天被保存下来。

所以我写《朝花朝拾》。

“朝花朝拾”的意思是：今日之花，今日拾起。  
它记录我的平凡生活、梦境、散文、小说、情绪与记忆。  
这里没有宏大的宣言，只有一个人慢慢生活、慢慢观察、慢慢写下自己的过程。

## 系列计划

目前计划整理以下内容：

- 《朝花朝拾·梦》：梦境记录与梦后感受
- 《朝花朝拾·家乡》：记录我的乡土人文
- 《朝花朝拾·大学》：记录我的大学人文

这些作品会按照时间慢慢补充，也可能在未来重新整理、修改、归档，形成不同的散文集或小说集。
